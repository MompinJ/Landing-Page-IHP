# Meridian One (Project One) - Cierre del proyecto SAP S/4HANA (Meridian Motors Group)

Presentacion de cierre de la Unidad 5 de "Evaluacion y gestion de proyectos tecnologicos" (UCC).
React 19 + Vite + framer-motion, sistema de diseño IBM Carbon (IBM Plex, esquinas rectas, escala azul).

- Textos y cifras: `src/data.js`. Diapositivas: `src/slides/s1.jsx`, `s2.jsx`, `s3.jsx`. Orden y transicion de cada una: `SLIDES` en `src/App.jsx`.
- Desarrollo: `npm install` y `npm run dev`.
- Publicar en el hub: `npm run build` y copiar `dist/index.html` a `presentations/cierre-sap-s4hana/index.html`.
  El build es un solo HTML autocontenido (vite-plugin-singlefile): fuentes e imagenes van dentro, funciona tambien con doble clic.

Atajos: flechas, espacio o clic avanzan; clic derecho o flecha izquierda regresan; F pantalla completa, O vista general,
B pantalla negra, C tarjetas de capitulo, H ayuda; `#n` en la URL salta a la diapositiva n.
